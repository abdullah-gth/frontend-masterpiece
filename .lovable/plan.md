# IT Services Frontend Website

## Goal
Build a complete, responsive one-page frontend inspired closely by the supplied reference image, while removing browser chrome, duplicate side previews, section numbers, and other mockup-only elements.

## Page structure
1. Header and large IT-services introduction
2. Service cards and “Why Choose Us” statistics
3. Four-step process
4. Featured case studies
5. Client testimonials
6. Blog and insights
7. Pricing tiers and FAQ
8. Location, contact details, newsletter, and footer

## Visual direction
- Bright white and cool mist-grey surfaces with restrained teal accents
- Compact, polished enterprise layout with crisp cards and subtle shadows
- Technical imagery, data panels, line charts, and a globe/map motif
- Strong centered headings, concise supporting text, and clear teal actions
- Responsive desktop, tablet, and mobile layouts with lightweight reveal motion

## Technical details
- Implement the single page at `/` with reusable React sections and semantic HTML
- Define all colors, typography, shadows, spacing, and motion as reusable design tokens
- Generate cohesive imagery for the main banner and case studies rather than embedding the screenshot
- Add working navigation scrolling, newsletter form feedback, pricing actions, and expandable FAQ rows
- Add page-specific title, description, Open Graph, and Twitter metadata
- Verify the final page in desktop and mobile browser sizes and resolve visual or runtime issues
